# 知识库预填输出模板

Markdown 是可编辑底稿。确认后再另出只读 HTML，见 html-viewer.md。

输出文件使用以下结构。每个模块的内容尽量详细，保留搜索到的原文。

文档末尾必须加一节「信源勾选表」，把 sources.md 里的必搜清单逐条写成：来源 / 状态 / 关键发现。

## 标注规则

在每条信息末尾使用以下标注：

- `（来源：{来源名称}）` — 双源一致、可写入正式口径
- **[已搜到-待确认]** — 只有单源，或年份/口径需要客户核实
- **[需客户补充]** — 公开搜索无法获取，需要客户提供
- **[冲突-待用户裁定]** — 多个来源说法不一致，必须两说并列，禁止自行选边
