# 信源等级、时效与回访

写入知识库前按本文件判断。本文件是唯一口径，不要在 SKILL.md 里再写一套。

## 信源优先级

1. 用户给的本地资料、内部口径、产品手册
2. 官网 / 官方商城 / 官方公众号 / 官方社媒
3. 工商、资质、政府、行业协会、权威认证
4. 主流行业媒体、财报、有署名的第三方评测
5. 电商详情页：只作卖点素材，不当独家事实
6. UGC（小红书 / 知乎 / 测评 / 问答）：只作口碑，不作工商、参数、荣誉的唯一依据

同一事实打架时：本地 > 官网 > 权威第三方 > 媒体转述 > UGC。
冲突必须两说并列，回访用户拍板，禁止自行选边。

## 时效

- 无年份，或早于近 2 年且无当年回证：标过时，不写入正式口径
- 融资、人数、价格、地址、Slogan、产品在售状态：以最新一次官方表述为准
- 旧域名、旧主体、旧产品名：记入「曾用/沿革」，不写进当前定位

## 交叉校对四问

每条准备写入的事实，必须能回答：

1. 来源是谁？
2. 一手还是转述？
3. 有没有第二个独立来源？
4. 当年还有效吗？

## 回访简报（落库前必须给）

1. 信源地图：官网、主体、官方账号、已打开的关键页
2. 已确认事实（最多 5 条）
3. 冲突项（列出选项，让用户选）
4. 已弃用的过时信息
5. 公开搜不到、必须客户补的 5 项
6. 请用户确认：哪些能写、哪些不能对外、哪些以本地口径为准
