# Artifact Design Profile

- Family: customer review viewer + internal markdown report
- Audience: 客户看 HTML；我方和客户改稿看 Markdown
- Visual system: GEO 晨光陶瓷（暖瓷底 + 唯一强调色钴蓝 #2f5bff）
- Hierarchy: 页顶查看说明 → 品牌一句话 → 模块正文 → 信源勾选表
- Density: 表格比长文优先；缺项用虚线空态，不用假卡片凑数
- Evidence: 来源芯片；冲突两说并列；禁止本机路径
- Rejected: 紫色渐变、玻璃拟态、contenteditable、把 HTML 当编辑器
