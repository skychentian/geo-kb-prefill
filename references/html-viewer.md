# 客户展示页（只读 HTML）

## 产品分工（不要改）

| 文件 | 给谁 | 干什么 |
|---|---|---|
| `[预填] {品牌}-品牌知识库.md` | 我方 + 客户改稿 | 唯一可编辑底稿 |
| `[预填] {品牌}-品牌知识库.html` | 客户查看 | 只读展示，方便打开、目录跳转、扫模块 |

HTML **不要**做成可编辑页，也不要 `contenteditable`。客户在浏览器里改会丢、会乱、也无法回写成知识库。

客户要改：在配套 Markdown 里改，或把意见发回，我们更新后再出一版 HTML。

## 触发时机

必须先完成检索，并让用户确认简报。用户说「确认 / 没问题 / 可以出 / 出展示页」之后，才生成 HTML。

未确认时只交简报，不交 HTML。用户明确说「直接出」时，MD 和 HTML 可一起出，但冲突项仍须标在页上。

## 视觉

对齐 GEO 系统「晨光陶瓷」：暖瓷底 `#f6f4ef`、内盘 `#fffefa`、唯一强调色钴蓝 `#2f5bff`。

复制 [templates/knowledge-base.html](../templates/knowledge-base.html) 再填内容。不要另起紫色渐变或通用 AI 卡片风。

对照成品：[examples/changhe-decoration.html](../examples/changhe-decoration.html)

## 填写规则

- 客户可见正文不出现 GEO、预填、爬虫、权重
- 页顶固定提示：此页仅供查看，修改请走配套 Markdown
- 侧栏目录对应全部模块；缺项模块也要在，标「待补充」
- 数字、荣誉、定位带来源芯片
- 待确认用琥珀标签，需补充用虚线空态，冲突两说并列
- 投诉/诉讼默认不进 HTML
- 禁止写入本机绝对路径
- 单文件，CSS 内联，无外链脚本

## 交文件时说什么

同时给两个路径，并写一句：

> 展示页给客户打开看。如果要改某一段，请直接改配套 Markdown，或把修改意见发回，我们再刷一版 HTML。
