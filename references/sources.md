# 信源等级、必搜清单与约束

写入知识库前按本文件判断。本文件是唯一口径。

## 信源优先级

1. 用户给的本地资料、内部口径、产品手册
2. 官网 / 官方商城 / 官方公众号 / 官方社媒
3. 工商、资质、政府、行业协会、权威认证
4. 主流行业媒体、财报、有署名的第三方评测
5. 电商详情页：只作卖点素材，不当独家事实
6. UGC（小红书 / 知乎 / 测评 / 问答）：只作口碑，不作工商、参数、荣誉的唯一依据

同一事实打架时：本地 > 官网 > 权威第三方 > 媒体转述 > UGC。
冲突必须两说并列，回访用户拍板，禁止自行选边。

## 必搜信源清单（每条都要勾）

检索结束时必须交一张信源勾选表，状态只能是：`已找到` / `搜过没有` / `本品牌不适用`。禁止跳过不记。

### A. 主体与资质

- 工商：天眼查 / 企查查 / 爱企查 / 国家企业信用信息公示系统
- 信用中国、行政处罚或经营异常（只记内部，默认不进客户展示页）
- 商标网 / 国家知识产权局 / soopat（自称有专利或技术时必搜）
- 官网荣誉/资质页、高新技术/专精特新公示

### B. 官方表达

- 官网：首页、关于我们、产品/服务、案例、荣誉、新闻、联系我们
- 官方商城：天猫 / 京东 / 自营商城（产品型必搜）
- 官方账号：微信公众号、视频号、抖音、小红书、微博
- 应用商店：App Store / 应用宝 / 官网下载页（有 App 时必搜）

### C. 权威第三方

- 百度百科 / 搜狗百科 / 维基（有则核，无则记搜过没有）
- 行业协会、标准委员会、地方经信/住建公示
- 行业报告：艾瑞 / 欧睿 / 易观 / 艾媒 / 地方协会年报
- 主流媒体：地方日报、界面、36氪、亿邦、新华/人民网地方站

### D. 市场与渠道

- 高德 / 百度地图门店与品类（本地生活、家装、餐饮必搜）
- 大众点评 / 美团（C 端本地品牌必搜）
- 招投标 / 政府采购网（B2B、工程、政企服务必搜）
- 招聘：Boss / 猎聘 / 官网招聘（用来核对业务线、规模，不当对外口径）

### E. 用户说法

- 小红书、知乎、百度知道、贴吧
- 电商评价（产品型）
- 黑猫投诉 / 聚投诉：只进内部风险备注，未经用户授权不进展示 HTML

### F. 竞品

- 每个竞品的官网首页 + 关于我们
- `{品牌} vs {竞品}`、行业榜单、同城/同品类盘点

## 时效

- 无年份，或早于近 2 年且无当年回证：标过时，不写入正式口径
- 融资、人数、价格、地址、Slogan、在售状态：以最新一次官方表述为准
- 旧域名、旧主体、旧品牌写法：记入「曾用/沿革」，不写进当前定位

## 交叉校对四问

1. 来源是谁？
2. 一手还是转述？
3. 有没有第二个独立来源类型？（官网+媒体算两类；两篇转载同一通稿不算）
4. 当年还有效吗？

## 写入约束

检索结论怎么进正文，见 voice-and-labels.md。这里只约束核验：

- 两个独立信源类型一致 → 正文直接写
- 单源或口径不稳 → 正文句末「待确认」
- 搜不到 → 正文写「待补充」，勾选表记 `搜过没有`
- 工商/参数/荣誉：禁止只用 UGC
- 投诉/诉讼：只进内部附件
- 禁止编造；禁止用「行业领先」顶替检索
- 勾选表只写 `[内部] {品牌名}-信源勾选.md`，不进客户正文

## 回访简报（落库前必须给）

1. 信源勾选表（已找到 / 搜过没有 / 不适用）
2. 已确认事实（最多 5 条）
3. 冲突项（列出选项，让用户选）
4. 已弃用的过时信息
5. 必须客户补的 5 项
6. 请用户确认：哪些能写进展示页、哪些只留在 Markdown
