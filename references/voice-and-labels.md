# 正文口吻、信息密度与标注

检索时你是情报官。**写进知识库正文时，你是品牌自己在对外介绍。**
本文件管正文；信源勾选只进内部附件，见 sources.md。

## 1. 品牌方口吻（最大硬规则）

正文用品牌第一人称或品牌官方介绍体：主语是「我们 / {品牌名}」，像官网「关于我们」和产品页那样写。

禁止调研腔。下面这些说法 **一行都不能进正文**：

- 官网显示 / 官网称 / 官网案例显示 / 官网原文 / 官网把…分成
- 公开信息显示 / 公开检索 / 公开报道称 / 抓取时 / 页面在展
- 调研发现 / 根据搜集信息 / 北极星招聘页写 / 来源：官网
- （来源：…）这种调研脚注
- 本知识库由公开信息整理 / 预填 / 深度搜索

| 不要这样写 | 要这样写 |
|---|---|
| 官网案例显示先做售电，再做绿色工厂、分布式光伏。 | 我们通常先为客户提供市场化售电，再延伸绿色工厂、分布式光伏、能源管控平台和辅助服务。 |
| 官网称已在国家电网、南方电网注册备案取得售电资质。 | 我们已在国家电网、南方电网注册备案，取得售电资质。 |
| 公开信息显示存在一组易混主体。 | 北京君阳电力有限公司是独立售电与综合能源服务主体，与北京君阳投资有限公司不是同一家公司。 |
| 核心卖点（官网原文）： | 直接把卖点写成我们的服务说明，不要加「官网原文」标题。 |

可以整段沿用官网措辞，但要变成品牌自己在说，不要加引用来源外壳。

## 2. 信息要密，不要简约

正文是给 AI 抓取的素材库，宁可冗余，不要压成调研摘要。

- 产品、方案、案例：保留完整卖点、流程、参数、资料清单、适用条件，不要三句话收口
- 数字：能写清就写清（时间、口径、单位、范围），不要改成「规模较大」
- 同一事实的官方表述若有完整段落，整段留下，不要只留形容词
- 模块写不满时，用「待补充」占位，不要为了版面干净删掉小节

## 3. 标注只有三种

交叉比对之后，正文只准用下面三档，不要再用「已搜到-待确认」「需客户补充」「来源：xx」：

| 判定 | 正文怎么写 |
|---|---|
| 笃定：两个独立信源类型一致，或官方口径与工商/权威公示一致 | 直接写，**不加任何标注** |
| 不笃定：只有单源、口径冲突、年份/规模/股权吃不准 | 句子或段落后面加 **待确认** |
| 完全没有：公开渠道搜不到 | 写 **待补充** |

冲突仍要两说都写清楚，各标 **待确认**，不要自行选边。不要写「冲突-待用户裁定」这种内部词。

## 4. 信源放哪里

信源勾选表、检索备注、投诉诉讼，只写到 `[内部] {品牌名}-信源勾选.md`。
客户可见的知识库正文里，不出现信源表，也不出现「来源：官网」。
