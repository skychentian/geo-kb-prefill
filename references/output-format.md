# 知识库正文模板

Markdown 是客户可见、可供 AI 抓取的品牌底稿。口吻和标注先读 [voice-and-labels.md](voice-and-labels.md)。确认后再另出只读 HTML。

每个模块尽量详细：产品说明、案例、资质、参数整段留下，改写成品牌自己在说，不要压成调研摘要。

信源勾选表不要写进这份正文，另存 `[内部] {品牌名}-信源勾选.md`。

## 标注规则

- 笃定：直接写，不加标注，也不加「来源：」
- 不笃定：句末加 **待确认**
- 没有：写 **待补充**
- 禁止：已搜到-待确认、需客户补充、官网显示、公开信息显示
